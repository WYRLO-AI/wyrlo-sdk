# Contributing

Issues and pull requests are welcome. By contributing, you agree that your contribution
is licensed under the Apache License 2.0. Run the tests of the package you change
(`npm test` in `typescript/`, `python -m unittest discover -s tests` in `python/`).

Please follow the [code of conduct](CODE_OF_CONDUCT.md). Runnable examples live in
[`examples/`](examples/): keep them working when you change an API.
