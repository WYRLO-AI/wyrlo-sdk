# Code of conduct

This project welcomes everyone who wants to make RAG answers more reliable.

- Be respectful and constructive: criticise code and ideas, never people.
- No harassment, discrimination, personal attacks or unwanted sexual attention, in any
  form or channel of the project.
- Assume good faith, and help newcomers.

Report unacceptable behaviour privately to contact@wyrlo.io (subject: "Conduct"). Reports
are handled confidentially. Maintainers may edit or remove contributions, and block
participants, who break these rules.
